O seu sistema tem que permitir saber quantos times é possível formar com o total de inscritos. O sistema deve permitir apenas uma inscrição por vez (botão "inscrever-se"). O sistema deve mostrar na tela o total de inscritos, o total de times possíveis e a quantidade de sobras (se houver). Para o campeonato acontecer, precisa ter pelo menos 4 times completos. Caso tenha 4 times completos, o sistema deve informar que o campeonato vai acontecer. DESAFIO
